Kod Apps Script Lengkap (doPost & doGet)

                        
Salin kod di bawah ke dalam Extensions > Apps Script di Google Sheets anda, kemudian Deploy sebagai Web App (Anyone):

                        

                            
const SHEET_NAME = "Rekod_Misi_Kata_Terbitan";

function getOrCreateSheet() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  let sheet = ss.getSheetByName(SHEET_NAME);
  if (!sheet) sheet = ss.insertSheet(SHEET_NAME);
  if (sheet.getLastRow() === 0) {
    const headers = ["Masa Penghantaran", "Nama Penuh Murid", "Kelas", "Modul / Aktiviti", "Markah / Status", "Jawapan Terperinci Murid (Tersusun)"];
    sheet.appendRow(headers);
    const headerRange = sheet.getRange(1, 1, 1, headers.length);
    headerRange.setFontWeight("bold").setBackground("#0a1633").setFontColor("#facc15").setHorizontalAlignment("center");
    sheet.setFrozenRows(1);
  }
  return sheet;
}

function doPost(e) {
  const sheet = getOrCreateSheet();
  const data = JSON.parse(e.postData ? e.postData.contents : "{}");
  sheet.appendRow([
    data.timestamp || new Date().toLocaleString("ms-MY", { timeZone: "Asia/Kuala_Lumpur" }),
    data.studentName || "Tanpa Nama",
    data.studentClass || "Tanpa Kelas",
    data.activity || "Aktiviti Am",
    data.scoreStatus || "-",
    data.formattedText || "-"
  ]);
  return ContentService.createTextOutput(JSON.stringify({ status: "success" })).setMimeType(ContentService.MimeType.JSON);
}

function doGet(e) {
  const sheet = getOrCreateSheet();
  const lastRow = sheet.getLastRow();
  if (lastRow <= 1) return ContentService.createTextOutput(JSON.stringify({ status: "success", records: [] })).setMimeType(ContentService.MimeType.JSON);
  const rows = sheet.getRange(2, 1, lastRow - 1, 6).getValues().reverse();
  const records = rows.map(r => ({ timestamp: String(r[0]), studentName: String(r[1]), studentClass: String(r[2]), activity: String(r[3]), scoreStatus: String(r[4]), formattedText: String(r[5]) }));
  return ContentService.createTextOutput(JSON.stringify({ status: "success", records })).setMimeType(ContentService.MimeType.JSON);
}

                    Peta Konsep Visual
                    
Bagaimana Kata Terbitan Terbentuk?

                    

                        Kata terbitan terbentuk apabila Kata Dasar (kata asal tanpa imbuhan) digabungkan dengan Imbuhan di salah satu daripada 4 kedudukan: di hadapan (Awalan), di belakang (Akhiran), mengapit serentak (Apitan), atau diselit di celah (Sisipan).
                    

                    

                        1. Awalan (ber-)
                        2. Akhiran (-an)
                        3. Apitan (ke-...-an)
                        4. Sisipan (-el-)
                    

                

                

                    
                    
                

            


            
            

                

                    

                        Eksperimen Interaktif
                        
Makmal Pembina Kata Terbitan

                    

                    
Pilih bentuk imbuhan dan kata dasar untuk melihat proses pembentukan kata secara langsung!

                


                

                    

                        

                            
1. Pilih Bentuk Imbuhan:

                            

                                
                                
                                
                                
                            

                        

                        

                            
2. Pilih Contoh Gabungan:

                            

                        

                    


                    

                        
ber- + main

                        
bermain

                        
Imbuhan awalan ber- bergabung di hadapan kata dasar main membentuk kata kerja tak transitif.

                    

                

            


            
            

                

                    

                        
                    

                    

                        
A. Pengenalan Konsep Asas

                        
Klik setiap kad di bawah untuk melihat contoh bergambar

                    

                

                

                    

                        

                            

                            Klik untuk Contoh
                        

                        
Maksud Kata Dasar

                        
Kata asal yang belum menerima sebarang imbuhan, akronim atau pengulangan.

                        

                            Contoh: main, tulis, cantik, lari.
                        

                    

                    

                        

                            

                            Klik untuk Contoh
                        

                        
Maksud Imbuhan

                        
Unit morfem terikat yang diimbuhkan pada kata dasar untuk membentuk perkataan baharu.

                        

                            Contoh: ber-, meN-, -an, ke-...-an, -el-.
                        

                    

                    

                        

                            

                            Klik untuk Contoh
                        

                        
Maksud Kata Terbitan

                        
Perkataan yang terhasil daripada proses pengimbuhan kata dasar melalui empat bentuk utama.

                        

                            Contoh: bermain, catatan, kecantikan, telunjuk.
                        

                    

                

            


            
            

                

                    

                    

                        
B. Empat Bentuk Kata Terbitan (Rajah Visual)

                        
Perhatikan kedudukan blok imbuhan berwarna berbanding kata dasar

                    

                


                

                    
                    

                        

                            1. Awalan
                            Di Hadapan
                        

                        
                        
                        

                            
ber- + main= bermain

                            
meN- + tulis= menulis

                            
peN- + jual= penjual

                        

                    


                    
                    

                        

                            2. Akhiran
                            Di Belakang
                        

                        
                        
                        

                            
catat + -an= catatan

                            
baca + -an= bacaan

                            
ajar + -an= ajaran

                        

                    


                    
                    

                        

                            3. Apitan
                            Depan & Belakang
                        

                        
                        
                        

                            
ke- + cantik + -an= kecantikan

                            
peN- + rawat + -an= perawatan

                            
meN- + ajar + -kan= mengajarkan

                        

                    


                    
                    

                        

                            4. Sisipan
                            Di Celah Kata
                        

                        
                        
                        

                            
tunjuk + -el-= telunjuk

                            
tapak + -el-= telapak

                            
gigi + -er-= gerigi
